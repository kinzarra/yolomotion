# Сурс → Рил («обсуждаем единорога»)

- **id**: unicorn-cafe
- **format**: reel (1080×1920), 17.5s
- **series**: standalone (русский, но не «ДЕНЬГИ · ПРОСТО» — личный мета-ролик)
- **hero color**: unicorn pink #FF2E93 — единственный сигнальный цвет
- **hook (first 2s)**: сырое селфи из кафе + плашка «ЭТО ВИДЕО СМОНТИРОВАЛ КОД»
- **face**: живой футаж автора и друзей (не HeyGen, ничего не синтезируется)

Мета-концепция: исходник — 15-секундное селфи с телефона, в котором автор
говорит «вот готовый сурс, мы этот сурс используем для того, чтобы дальше…»
и клип обрывается на полуслове. Рил сам заканчивает фразу: «…сделать вот
это» — то есть себя. Живой звук футажа = войсовер; капшены — караоке по
реальным word-таймстампам (Apple Speech, on-device), не по весовой оценке.

## Beats
1. **hook** (0–3.8, src 0–3.8) — селфи, пуш-ин; плашка-хук сверху, уходит к 3.5s
   - улика: сам футаж, full-bleed (контейнер studio — весь рил и есть улика)
2. **cafe** (3.8–6.95, src 3.8–6.95) — камера панорамирует на друзей;
   на слове «единорога» (5.82) — слэм «ЕДИНОРОГА» в hero pink, капшены молчат
3. **stare** (6.95–8.45, src 6.95–8.45) — немая пауза, три жёстких
   диджитал-панч-зума (кадры 0/17/32, каждый со звоном); слэм держится,
   три точки и моно-чип `no comment`
4. **source** (8.45–10.7, src 9.50–11.75, джамп-кат −1.05s) — снэп-зум;
   файловая карточка source.mp4 · 592×1280 · 15s
5. **use** (10.7–14.13, src 11.75–15.18) — «этот сурс используем, чтобы
   дальше…»; HUD-захват: скобки, mono-лог (analyze/cut/captions), прогресс
6. **outro** (14.13–17.5) — хард-кат в чёрный: «…СДЕЛАТЬ ВОТ ЭТО.» +
   yolomotion · снято на телефон · смонтировано кодом + вопрос

## Voiceover
Живой звук, не TTS. Два непрерывных куска (чтобы амбиент кафе не рвался):
- `01-hello` = src 0.00–8.45 → старт 0.00
- `02-source` = src 9.50–15.46 → старт 8.45 (хвост «дальше…» звенит 0.28s
  поверх начала outro — так и задумано)

## Pipeline (нестандартная часть)

Живой футаж → капшены по настоящим таймингам, а не по весовой оценке:

```bash
# 1. ASR по звуку исходника (macOS Speech, on-device с фолбэком в сеть)
#    сборка .app обязательна — см. шапку scripts/transcribe.swift
open /tmp/Transcribe.app --args /abs/full.wav \
  packages/video/scripts/asr/unicorn-cafe.json ru-RU
# 2. рез как данные: сцены + слайсы аудио + капшены из одного конфига
cd packages/video && node scripts/gen-source-cut.mjs \
  scripts/cuts/unicorn-cafe.json --slice
# 3. уровень и durations.ts — штатным скриптом
npm run voiceover -- scripts/voiceover/unicorn-cafe.json --normalize-only
```

`scripts/cuts/unicorn-cafe.json` — единственное место, где живут тайминги
монтажа, и все они в координатах ИСХОДНИКА. Сдвинуть джамп-кат = поправить
одно число: сцены, старты аудио и капшены пересчитаются вместе.

## Deviations
- Пайплайн TTS-войсовера не применяется: звук — родная дорожка футажа,
  голос настоящий, а не клон. Манифест хранит транскрипт и слайсы.
- Сетка 0.5s для длин битов нарушена: длины продиктованы паузами живой
  речи (границы резов сидят в паузах), иначе рвётся синхрон.
- Джамп-кат вырезает 1.05s мёртвой паузы (src 8.45–9.50) — тренд-грамматика
  и подарок ретеншену.
- Слово на src 2.76–3.45 неразборчиво (распознаётся как «Creat»); в капшенах
  на этом месте пробел, звук не тронут.
- «обсуждаем единорога» не капшенится — эти слова несёт слэм-заголовок
  (аналог ~PAGE движка).
- Хук переписан: вместо транскрипта первой фразы — плашка
  «ЭТО ВИДЕО СМОНТИРОВАЛ КОД» (правда в момент просмотра, число не нужно).
- Ролик 17.5s против ~30 обычных: второго поворота в исходнике нет —
  по правилу ретеншена режем короче, а не паддим.
