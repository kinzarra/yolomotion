# ТЗ: TikTok @kinzarra упёрся в 800 просмотров — что делаем

Для локального Claude. Разбор сделан 2026-10-04 в облачной сессии: данные TikTok
сняты через yt-dlp, аналитика — скриншоты TikTok Studio от автора, содержимое
S3 `yoclips` просмотрено (только чтение). Сырые таблицы рядом:

- `tiktok-2026-10-04.tsv` — все 88 роликов: дата, просмотры, лайки, комменты,
  репосты, сохранения, длина, заголовок.
- `s3-videos.tsv` — все 92 ролика из `s3://yoclips/videos/vN/`: дата рендера,
  slug шаблона (из `template.tgz`), число клипов озвучки, есть ли HeyGen.

## 1. Проблема

88 роликов за 45 дней (2 в день), **ни один не прошёл выше 832 просмотров**.

| | значение |
|---|---|
| Просмотры, медиана / максимум | 752 / 832 |
| Всего за 60 дней | 58,9K просмотров, 323 лайка, 61 коммент, 22 репоста |
| Лайки / просмотр | 0,54% (у роликов со второй волной — 3–8%) |
| Подписчики | 38 (0,07% от просмотров), заходов в профиль — 57 |
| Трафик | 98,9% For You, поиск 0,3% |

Плато ровное с 25 августа: это размер первой тестовой выборки TikTok. Ролик
показывают ~800 людям, сигналов не хватает, второй волны нет. Длина, тема и
наличие лица на просмотры **не влияют** (медиана ~750 во всех корзинах) —
значит, просмотры определяет выборка, а не ролик.

### Причина: зритель уходит на первой секунде

| Ролик | Длина | Средний просмотр | Досмотр до конца |
|---|---|---|---|
| Госдолг США $40 трлн (лицо + счётчик) | 85,5 с | 13,7 с (16%) | 5,19% |
| «ИИ вошёл сам» (лицо) | 50,5 с | 10,8 с | 6,21% |
| Беднейшие страны (график, без лица) | 45,2 с | 8,8 с | 6,91% |

- TikTok по госдолгу: *«Most viewers stopped watching at 0:01»*; к 1–2 с остаётся
  ~50%, к 10 с ~20%.
- Средний просмотр **~9–14 с независимо от длины и формата**. График без лица
  держит хуже, чем с лицом — аватар не причина.
- 57% «returning viewers» при 0% подписчиков: TikTok крутит ролики одному и тому
  же кругу, он узнаёт обёртку и листает.
- География не причина: поисковые запросы русскоязычные, 98,9% — For You.

Для сравнения: на YouTube Shorts у того же контента «выбор в ленте» 70%
(`.claude/skills/reel-production/references/retention.md`). Лента TikTok
жёстче. Правило «не трогать хук, если досмотр в норме» здесь **не действует**:
не в норме.

## 2. Гипотеза пилота

Если ролик длится примерно столько же, сколько его смотрят (15–25 с), а первая
секунда сразу выдаёт утверждение, то досмотр вырастет с ~6% до 25%+ и TikTok
даст вторую волну. Проверяем на 10 роликах за 2 недели, **1 в день вместо 2**.

Критерии (TikTok Studio → Video analysis → Overview):
- средний просмотр ≥ 50% длины;
- досмотр до конца ≥ 25%;
- просмотры > 832 хотя бы у 2 из 10.

Если досмотр вырос, а просмотры остались ~800 — дело в теме/подаче; следующий
шаг тогда — сузить рубрику (лучше всего реагируют «ИИ × деньги» и истории людей:
Портнягин, Чжао, Маск).

## 3. Где лежат исходники и как их взять

Ролики делает YoClips (clips.yoloco.io). Метаданные — в его Postgres, файлы — в
S3 (Yandex Object Storage, бакет `yoclips`, переменные `S3_ENDPOINT_URL`,
`S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_AVATAR_BUCKET` — их уже понимает
`packages/worker/src/env.ts`).

На каждый ролик `s3://yoclips/videos/vN/`:

```
other/template.tgz        код шаблона: src/templates/<slug>/ (+ scripts/presenter/<slug>.json)
voiceover_clip/NN-beat.mp3 озвучка по битам, уже нормализованная
presenter/pN-*.mp4        HeyGen-вставки (если были)
image/*.jpg|png|webp      фото, на которые ссылается шаблон через staticFile("images/<slug>/…")
out.mp4                   то, что ушло в TikTok
still/poster.jpg
```

**Postgres для перемонтажа не нужен.** Шаблоны собраны на движке этого репо
(`../../reel`, `../../../theme`). `durations.ts` внутри архива пустой: длительности
приходили из `video.props` в БД. Их не берём из БД, а заново меряем по mp3
(`npm run voiceover -- … --durations-only` или ffprobe), это то же значение.
Из БД пригодятся только `series` / `episode` (пропсы схемы); их видно и на
`still/poster.jpg`.

Восстановление ролика `vN` в рабочую копию:

1. `template.tgz` → распаковать в `packages/video/` (пути внутри уже
   `src/templates/<slug>/…`), зарегистрировать в `templates/index.ts`.
2. `voiceover_clip/*.mp3` → `packages/video/public/voiceover/<slug>/`.
3. `presenter/*.mp4` → `packages/video/public/presenter/<slug>/`.
4. `image/*` → `packages/video/public/images/<slug>/`.
5. `durations.ts` — сгенерировать замером mp3, руками не писать (правило CLAUDE.md).
6. `npm run stills -- <slug>-reel --every 2.5` — убедиться, что собирается так же,
   как `out.mp4`.

Хорошо бы оформить это скриптом `scripts/yoclips-pull.mjs <vN>` (по аналогии с
`deliver --restore`).

## 4. Задача

### 4.1 Перемонтаж готовых роликов в 15–25 с (бесплатно)

Взять 3 ролика, у которых уже есть озвучка по битам. Из каждого оставить
3–4 бита по схеме **утверждение → поворот → цифра → вопрос**, остальное выкинуть
(не сжимать). Лишние строки убрать из `LINE_SPECS`, сцены пересчитаются сами
(`buildScenes`). HeyGen-вставку хука оставить, если её клип остаётся первым, —
тогда новых трат нет.

Пример — `v99` / `nalogi-2027-koshelek` (TikTok 03.10, 756 просмотров, 65 с).
Клипы (сек, до `VO_RATE` 1.08): hook 6.2, bill 7.1, turn 6.2, savings 9.9,
question 8.5, apartment 8.2, status 5.0, factcheck 7.5, close 5.6.
Вариант: `hook + turn + savings + close` ≈ 27.9 с сырых ≈ **~27 с** ролика.
Внимание: `03-turn` начинается с «Но…» — без `02-bill` звучит обрубком;
проверить на слух, и если плохо, это кандидат на одну новую строку (см. 4.2).

Другие кандидаты — свежие ролики с HeyGen из `s3-videos.tsv`
(`portnyagin-sentence` v97, `what-is-mcp` v95, `ai-evolution` v90 — у них
больше всего лайков/комментов).

Сохранять как новый шаблон `<slug>-short` (композиция `<slug>-short-reel`),
оригинал не трогать.

### 4.2 Первая секунда

Это главное изменение, перемонтаж без него ничего не проверит.

- Кадр 0: 2–4 слова утверждения **крупно и сразу целиком**, без анимации
  появления. Нельзя: счётчик, который «доезжает» до цифры (госдолг), плашка
  с датой, перечисление («Вклад. Квартира. Посылка…»).
- Движение уже в кадре 0 (наезд, тряска на ударном слове), а не статичная
  подложка.
- Первое слово озвучки — сразу, с ударением; без вступления.
- Если готовая строка хука — перечисление или подводка, её надо переписать:
  одна новая строка ElevenLabs стоит копейки, но **по правилу репо: сначала
  оценка, подтверждение автора, потом синтез**. Голос — `${ELEVENLABS_VOICE_ID}`.
  Новая строка = новый `durations` и новые тайминги HeyGen-вставки — если
  вставка лежит на старой строке хука, её придётся делать заново (платно,
  dry-run → подтверждение).
- Повтор с конца на начало (как `phone-check` / `dollar-wait`): последний кадр
  CTA совпадает с кадром 0 хука.

### 4.3 Три варианта первого кадра

Чтобы за 10 роликов понять, что держит лучше: (а) лицо + утверждение,
(б) текст на весь экран, (в) видео-доказательство (`fetch-footage`).
Чередовать, записывать, какой вариант на каком ролике.

### 4.4 Замеры

- Добавить в `retention.md` раздел **TikTok** с цифрами из п.1 и строкой на
  каждый ролик пилота (средний просмотр, % досмотра, просмотры, отметка «где
  ушли» из TikTok Studio).
- Опционально: `worker:stats` сейчас снимает только YouTube. Статистику TikTok
  можно снимать без ключей:
  `yt-dlp --impersonate chrome --flat-playlist -J https://www.tiktok.com/@kinzarra`
  (нужен свежий `yt-dlp[default,curl-cffi]`; поля `view_count`, `like_count`,
  `comment_count`, `repost_count`, `save_count`, `duration`) → `metric_snapshot`.
  Средний просмотр и досмотр так не достать — только из TikTok Studio.

### 4.5 Потом, если пилот сработает — в продукт

Перемонтаж как функция YoClips: в `video.props` поле со списком битов (`beats`
уже поддерживается движком как override) + отдельная задача рендера из тех же
ассетов в S3 без новых покупок. Это изменения в репо YoClips, не здесь.

## 5. Что НЕ делать

- Не выпускать ещё 88 роликов в той же обёртке: тот же круг зрителей её
  узнаёт и листает.
- Не сжимать 60 с в 25 с ускорением — выкидывать биты целиком.
- Не тратить ElevenLabs/HeyGen без оценки и подтверждения автора.
- Не коммитить бинарники (mp3/mp4/картинки) в git — только код; файлы живут в S3.
